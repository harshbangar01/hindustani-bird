# hindustani-bird
🕹️ Hindustani Bhau Flappy Bird

"Bhau udta hai... pipe se takrata nahi!"
A funny desi twist on the classic Flappy Bird, featuring our very own Hindustani Bhau! 🧔🔥

Try to keep Bhau flying through those green pipes without crashing — kyunki agar takra gaya…

“Bhau ka game khatam!” 😤

🎮 Game Features

🧔 Bhau as the bird – Meme-style playable character.

🏗️ Classic Flappy Bird gameplay – Tap or press space to fly.

📈 Score counter – Dekhte hain kitna door uda Bhau.

🎵 Retro graphics and sounds – OG Flappy vibes.

🤣 Desi humor edition – Made just for fun!

🕹️ How to Play

Press SPACE or CLICK to make Bhau jump.

Avoid the pipes – ek bhi lag gaya, game over boss!

Score badhao – jitna zyada uda, utna bada Bhau!

⚙️ Tech Stack

HTML5 Canvas 🖼️

JavaScript (Vanilla JS) ⚡

CSS3 🎨

💻 Installation & Run

Clone this repo:

git clone https://github.com/your-username/hindustani-bhau-flappybird.git


Open the folder:

cd hindustani-bhau-flappybird


Run the game:

Open index.html in any browser

Or use VS Code Live Server for smoother play
